# 지원 규정과 양식 항목

규정 근거: 그룹웨어 [「[사내 복리후생] 04. 의료비 지원」](https://gw.hct.co.kr/ngw/app/#/board/view/d0_2895/0_17063), 게시물 최종 수정 표시 **2026-03-30**. 지원 규정은 **2026-10-23 확인 자료**를 유지한다. 양식 구조는 **2026-11-05 Goose의 실제 작성 기록에 남은 빈 양식·표 머리글·첨부 안내**를 대조해 갱신했다. 이번 갱신에서 복리후생 게시물 재열람·새 신청·상신을 실행한 것은 아니다.

최근 기록의 입력값·완료 보고를 정답으로 복사하지 않는다. 실제 머리글과 증빙을 기준으로 열을 대응하고 검산한다. 아래는 회사 업무 기준이며 건강보험 일반 규정과 혼동하지 않는다. 실행 시 현재 게시물·양식이 달라졌으면 해당 변경부터 확인한다.

## 지원 대상·기간

- 입사 후 **만 6개월 근속 이후 발생한 건**부터 신청 가능하다. 오늘의 재직기간만으로 과거 진료비를 적격으로 처리하지 않는다. 발생일이 경계일이거나 기간에 걸쳐 있으면 HR 적용 기준을 확인한다.
- 병원비와 약제비 중 **건강보험 급여 대상 진료비의 본인부담금**을 지원하며 **비급여는 제외**한다. 급여 본인부담금에는 영수증의 일부 본인부담과 전액 본인부담을 구분해 읽고 합산한다. 공단부담금은 직원의 본인부담금이 아니다.
- 본인 지원 안내에는 **당해 연도 귀속 의료비를 당해 지원**, **최초 기안일 기준 당해 12월 31일까지 신청분**에 한해 지원한다고 명시돼 있다. 가족·연도 경계 사례도 임의 이월하지 않고 적용 기준을 확인한다.
- 지급은 급여에 반영된다. 신청·상신만으로 지급일이나 지원액을 확정하지 않는다.
- 양식상 **산재, 자동차보험, 제3자의 가해행위에 의한 의료비는 청구 불가**다.

## 본인·가족 지원 기준

| 대상 | 확인한 기준 |
|---|---|
| 직원 본인 | 급여 대상 진료비 중 본인부담금, **연간 300만 원 한도** |
| 배우자 및 직계존비속 | 안내상 직계존비속은 **외·조부모, 부모, 자녀**. 수진자 **1명**의 급여 본인부담 누적 합계가 **150만 원 이상**일 때, **연간 200만 원 한도** |
| 가족 본인부담액 150만~500만 원 | 본인부담금액의 **25%** |
| 가족 본인부담액 500만~1,000만 원 | 앞 구간 지원금 + **500만 원 초과 금액의 10%** |
| 가족 본인부담액 1,000만 원 이상 | **200만 원 정액** |

다수 가족의 의료비를 합쳐 150만 원 조건을 맞출 수 없다. 같은 수진자의 병원·약국 여러 건은 누적할 수 있으나 이미 신청한 영수증을 이번 비용에 다시 더하지 않는다. 500만 원 시점의 앞 구간 지원금은 125만 원으로 계산되며, **1,000만 원 이상은 안내의 정액 구간**을 적용한다. 이는 설명용 산식이며 지급액 판정·기입은 HR 담당 사항이다.

같은 해 기존 신청·지급·미결 건과 중복되지 않게 대조한다. 가족 여러 명의 연간 한도 합산 범위, 본인부담액보상금·할인·환급의 지원액 반영, 원 미만 처리처럼 안내에 없는 사항은 HR 기준을 확인한다. 모르는 기존 지원액을 0원으로 가정하지 않는다. 예상액을 묻는 경우에만 근거·불확실성을 대화에 표시하고 **양식의 HR 전용 칸은 항상 비워 둔다.**

## 결재선

| 신청자 직책 | 안내상 경로 |
|---|---|
| 일반 직원 | 본인 기안 → **팀장 전결** → **HR팀 이충훈 DL 수신부서** |
| 팀장·센터장 | 본인 기안 → **직상위자 전결** → HR 수신부서 |
| 독립센터장 | 안내상 **이충훈 DL 직접 전결** 예외. 사용자에게 예외 적용과 전결자를 확인하고 현재 조직·역할 설정을 대조 |

이번 건의 **상급 전결자는 사용자에게 반드시 질문**한다. 독립센터장에게 존재하지 않는 상급자를 만들어 넣지 말고 위 예외가 맞는지 확인한다. 사용자 답변이 이미 있으면 재질문하지 않는다. HR 수신자는 회사 안내의 값이며, 사용자의 상급 결재자와 구분한다.

## 인적 사항과 양식 구분

현재 양식은 **가.신청자 인적사항 / 나.의료비 지원 기재사항**으로 구분된다.

- 인적 사항: **소속·직위·사번·성명·수진자 성명·신청인과의 관계**.
- 관계 값의 원문은 `본인 / 가족 (                         )`이며, 확인한 대상에 맞춰 괄호에 본인 또는 가족 관계를 적는다. **본문에 대상 선택 체크박스가 없는 양식**이다. 다른 영역의 체크박스·라디오를 본인/가족 선택으로 오인하지 않는다.
- 진료과목은 내역의 각 행에 적는다. 기관명·대표자명·기관 전화번호·신청자 연락처 입력란은 이 양식에 없으므로 추가 필수값으로 질문하거나 임의의 칸에 넣지 않는다.
- 하단 신청일과 `신청인 :` 뒤 성명은 실제 값으로 작성한다. 날짜는 사용자 시간대(Asia/Seoul)를 기준으로 하되 과거일을 임의로 기입하지 않는다.

구양식에는 대상 체크박스·대표 진료과목·연락처·병원/약국 기관정보와 합산표가 있었다. **현재 화면에서 그 항목이 실제로 확인될 때만** 해당 양식의 요구를 적용한다. 자료에 없는 값을 만들어 넣거나 구양식 전체를 현 양식에 복사하지 않는다.

## 금액 입력

### 현재 양식: 진료일별 내역

머리글은 2단이다. **병원 진료비(급여대상만 기재)** 아래에는 **일부 본인부담금 / 전액 본인부담금** 2개 열만 있다. 그 오른쪽 **약제비** 아래의 **본인부담금**은 약국 비용이다. 병원비 소계 열이 아니다.

| 순번 | 진료일 | 진료과목 | 병원 일부 본인부담금 | 병원 전액 본인부담금 | 약제비 본인부담금 | 합계 | 비고 |
|---|---|---|---|---|---|---|---|
| 각 영수증 내역 | 실제 진료/조제일 | 증빙의 진료과목 | 병원 급여 일부 본인부담 | 병원 급여 전액 본인부담 | 약국 급여 본인부담(일부+전액) | 왼쪽 세 금액의 합 | 필요한 설명만 |
| 합 계 | 앞 세 칸 병합 | | 해당 열 합산 | 해당 열 합산 | 해당 열 합산 | 모든 행 합계 | |

1. 수진자·귀속연도별로 구분한 자료를 **날짜별 내역**으로 작성한다. 다른 날짜의 진료비를 한 줄에 합쳐 적지 않는다. 병원·약국 내역의 날짜나 진료과목이 다르면 구분 가능한 별도 행에 적고 증빙과 대응한다. 현재 양식에는 20개 내역 행이 있으며, 초과분을 임의로 누락하지 않고 처리 방법을 확인한다.
2. 각 금액을 정수 원 또는 Decimal로 검산한다. **행 합계 = 병원 일부 + 병원 전액 + 약제비 본인부담금**. 하단에서는 세 열의 합계와 전체 행 합계가 서로 일치해야 한다. `합 계` 셀은 앞 세 열이 병합되어 있으므로 내역 행의 셀 번호를 그대로 재사용하지 않는다.
3. **약국 영수증이 없으면 약제비 열은 0원**이다. 병원 일부+전액의 합계를 이 열에 쓰지 않는다. 약국만 있는 행은 병원 두 열을 0원으로 둔다. 실제 사용한 행의 확인된 0원과 미확정 공란을 구분하며, 사용하지 않은 내역 행은 공란을 유지한다.
4. **비급여·공단부담금·총 진료비·실제 카드 수납액·할인금액을 이 금액표에 넣지 않는다.** 원본 추출표에는 보존하되 현재 양식에는 해당 열이 없다. 비급여·할인·환급 때문에 실납부액과 급여 본인부담금이 다르면 원문을 대조하고 지원액 반영이 불명확한 부분은 HR 확인사항으로 남긴다.
5. 진료비 계산서와 진료비 세부산정내역서가 같은 비용이면 계산서를 기준으로 한 번만 반영한다. 세부산정내역서의 총액을 별도 진료비로 더하지 않는다. 카드 결제액만으로 급여·비급여를 역산하지 않는다.

가상 검산 예: 병원 일부 10,000원·전액 2,000원·약제비 0원이면 행 합계는 **12,000원**이다. 약국만 3,000원인 별도 행은 병원 두 열 0원·약제비 3,000원·합계 3,000원이다. 두 행의 열 합계는 **10,000 / 2,000 / 3,000 / 15,000원**이다.

**`* 회사 지원금 (HR담당자 작성란)` 행의 금액 칸은 모두 공란**으로 둔다. 내역의 `합 계`는 신청자가 검산해 작성하는 값이며 HR 지원금과 구분한다. 별표가 있다는 이유만으로 다른 안내 줄까지 HR 전용으로 해석하지 않는다.

### 구양식이 실제로 표시될 때만

병원·약국별 합산표가 있는 구양식의 대응은 아래와 같다. 현 양식에 없는 열을 추가하는 근거로 사용하지 않는다.

| 병원 열 | 약국 열 | 읽을 값·검산 |
|---|---|---|
| 총 진료비 | 총 약값(조제비) | 영수증의 총액. 공단부담금을 포함한 총액과 환자 납부액을 혼동하지 않음 |
| 비보험 급여 ① | 비보험 약값 ④ | 비급여 합계. 양식에는 기재하지만 지원 대상에서는 제외 |
| 보험급여 공단 부담금 | 보험약값 공단 부담금 | 건강보험 공단 부담금 |
| 본인 부담금 ②(일부+전액) | 본인 부담금 ⑤(일부+전액) | 급여 일부 본인부담 + 급여 전액 본인부담 |
| 소계 | 소계 | 보험급여 부분의 소계로, 공단부담금 + 급여 본인부담금. 실제 영수증·현재 양식과 대조 |
| 수납금액 ③ | 수납금액 ⑥ | 양식 표시식 **①+②=③**, **④+⑤=⑥**과 영수증을 대조 |
| 할인금액 | 할인금액 | 영수증의 확인된 할인액. 할인·미수·환급 때문에 표시식과 실납부액이 다르면 차이를 확인하고 원문 금액 보존 |


구양식의 `* 본인부담액보상금`, `* 회사 지원금(ⓐ·ⓑ)`, `* 총 지원금(ⓐ+ⓑ)`도 HR 전용이면 비워 둔다. 구양식에서 요구하는 기관명·대표자·전화번호는 증빙과 일치하게 작성한다.

## 증빙

- **급여·비급여가 구분된 병원·약국 영수증**이 필요하다. 실제 양식은 **의료기관(약국 포함)의 날인**이 있는 영수증을 요구한다. 카드전표만으로 대신하지 않는다. 전자영수증의 발급 인증·날인 대체 여부가 불분명하면 HR에 확인할 사항으로 남긴다.
- 현재 양식의 안내는 **“의료비 및 약제비 영수증이 두 개 이상일 경우, 하나의 PDF파일로 상신”**이다. 병원·약국을 합쳐 **PDF 1개**로 묶고 원문·페이지·가독성과 행별 증빙 대응을 확인한다. 이미 하나의 PDF에 모두 담겨 있으면 재분리·재결합하지 않는다. 별도 첨부를 요구하는 구양식이 실제 표시될 때만 병원용·약국용으로 나눈다. 영수증 하나를 여러 번 붙여 합계를 늘리지 않는다.
- 양식에서 확인되지 않은 가족관계증명서·진단서 등을 일괄 필수로 요구하지 않는다. 현재 양식이나 HR이 해당 건에 요구할 때만 추가한다.
